排谷机器人 · 前端 检查中…

展示页

排位表 + 消息流 + who-whats + 状态。5s 增量轮询、keyed diff、smart-scroll，不打断划词/点击/滚动。支持 local / remote 数据源。

管理面板

编辑 config：LLM prompt、商品目录（items/variants）、预存用户、时段窗口、白名单、展示参数。revision 乐观并发 + 409 冲突提示；拉取群成员。

模拟器

真实群成员身份切换/新建、时间偏移 ±DD HH MM SS、发送消息、转录与实时排位。走与真实链路完全相同的流水线。

重放步进

逐条消息回放排谷：步进/播放、累积排位表与状态差异高亮（新增/释放/前移/包尾/管理员）、列视图、Mermaid 视图、who-whats、核对条与单元格↔消息双向联动。

结算 · 下单表

调价（加减/直设）、折扣（满减/全单、份数 n/-1、A/B 范围）、特典档位（多档各自价格）、减均选项；试算结果表 + 特典清单；拖拽 item → 包手动调整并即时试算；特典最多化 vs 折扣最大化并排对比。

API 契约见 docs/DESIGN.md §5（默认 http://127.0.0.1:21081）。 可用 ?api=<base> 或页面内联 window.PAIGU_WEB 覆盖。 建议用 python -m http.server 从 127.0.0.1 打开（CORS 允许 http://127.0.0.1:*）。
