轮次管理（U3）
轮次标识 round_id 与展示名 title 可以不同。 round_id 是稳定标识：用于消息日志 data/messages/<round_id>.jsonl、 快照目录与远程 rounds/<round_id>/current；创建后建议不再改动。 title 仅用于界面展示。
激活模式：continue＝仅切换（无既有状态时等价 fresh）；fresh＝切换并清空内存排位；replay＝切换并自动计算重放。切换与重放互不绑定。

阶段时间窗（round.phases）
字段 phase / start_ms / end_ms；phase ∈ Phase0、PhaseI、PhaseII、PhaseIII、Settling、Locked；半开区间，空列表 = 不限制。日期旁显示相对日（周几 + 今天/明天/后天/X 天前/后）。
商品目录（种类：拼团 / 单领 / 整盒 / 特典）
价格以「分」为单位。变体显示 原价 A ± 调价 B = 最终价 C：改 A 或 B 联动 C，改 C 联动 B，A 永不联动； + 为红、- 为蓝。 class（A/B）由「种类 + 是否有变体」自动推导（有变体⇒A，无变体⇒B），只读显示。
