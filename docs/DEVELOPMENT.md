# 公开协作：无接收器的隔离检查

不需要NapCat、小号、真实群/名单/配置或模型密钥。只需Rust、Node和Git；桌面额外需仓库Playwright及Chromium（安装方法见[桌面说明](../tests/e2e/README.md)）。本入口不安装依赖、不部署、不重启常驻服务。

```powershell
npm run check         # 格式、严格lint、构建、隔离核心、脚本/文档、公开CLI、隐私
npm run check:full    # 以上全部＋既有完整桌面套件
npm run test:check    # 仅检查入口自测
npm run test:docs     # 仅现行文档本地链接与FUNCTIONAL源码符号
```

入口先在任务自己的临时目录创建禁用模型/群回复的公开配置，重定向轮次、消息、事件、结算、成员与系统临时目录。Rust测试由Cargo编译后，从隔离目录直接运行实际测试程序，避免Cargo默认为仓库根目录而意外读取真实相对路径。构建复用仓库target；隐私扫描**有意只读**仓库私有源以识别泄露，但不打印匹配内容，不修改源。测试完成/失败均清理任务临时目录；中断只停止此入口启动的进程树。

完整桌面复用现有套件，不新增模拟器：1920×1080、100%、DPR1，使用占位名单和测试轮、本地假接收器/模型回包，不连接真实接收器或真实模型。入口清除继承的专项过滤，防止少跑用例误报全套；自动截图写本次临时目录，结束清理。需持久截图时可单独运行桌面套件并显式设置其输出路径，不使用本入口的临时截图作为已交付截图。

## 私有夹具（显式选择，缺省不是通过）

```powershell
# 路径由使用者在本机填写，禁止把私有输入/输出提交或贴入Issue
npm run check:full -- --samples 'C:\private-fixtures' --settlement-fixture 'C:\private-reference.json' --xlsx
```

- `--samples <root>`：源目录含sample1、sample2各自的round_config.json、queue.jsonl、expected_allocation.json；只复制这三项到隔离目录，重放并逐格比较，不改原夹具，不复用旧out冒充本次结果。无该选项打印NOT RUN。
- 结算参考默认使用已跟踪的公开夹具，复制到隔离目录再单独执行对应测试，核对确实运行1项而非静默返回。E2基线为318核心＋1参考=319项；后续新增测试以实际输出为准，参考始终另计1项，不需要私有源工作簿。`--settlement-fixture <json>`仅用于显式替换参考；指定但缺失即失败，诊断不显示私有内容。
- `--xlsx`：选择本机私有两份工作簿回归，需既有只读解析器/夹具构建器和openpyxl。所有产物临时写入；比较后校验整个语料及源表哈希未变。指定但缺源表/依赖时失败，不降级通过；无该选项打印NOT RUN。
- `--ui`：执行完整桌面，省略明确NOT RUN；因此 `npm run check` 成功不表示UI通过。

任一门禁失败即非零退出，后续不跑；私有重放诊断隐藏，仅输出聚合结果。全部PASS只指本次**明确请求**的门禁。未知参数、缺显式路径及不完整输入不能伪装成功。真实NapCat、真实模型网络、公网/CF部署及共享Git历史修改都不在范围内。

## 提交边界

接收器故障开发无需真实NapCat：默认核心检查含阻塞sink/本地WS echo、256帧积压、文件故障与重启恢复；`--ui`含设置接入状态/键盘重试的占位故障夹具，不能冒充真实接收器测试。待处理原始帧与完整备份均属私有数据，不进库；见 [入站合同](./SPEC-DURABLE-INTAKE.md)。

只提交源码、公开模板与占位测试。真实名单可通过受控私下渠道另行共享，但不是开发/测试必需。隐私扫描同时检查暂存索引和工作副本；新增文件应加入暂存后再跑扫描。检测不是完整DLP或历史匿名化证明，提交前仍需检查差异，私有配置/备份/消息日志不进入公开仓库。

- 当前夹具在轮次JSON增加 `"fixture_version":2`。允许当前规则改单、阶段、`whitelist_members`、`members.cn_overrides`（或顶层cn_overrides）与显式merge；模型始终关闭，cache_path无论传什么都不读取。合并仍默认关，排与撤分开。
